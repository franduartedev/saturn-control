# Keycaps SATURN v1

Idea simple para imprimir las primeras keycaps:

```text
PLAY   PREV   NEXT
MUTE   VOL-   VOL+
```

Alternativa más flexible:

```text
S1 S2 S3
S4 S5 S6
```

Si las keycaps no van grabadas, podés imprimirlas lisas y usar etiquetas/íconos intercambiables según perfil.

Recomendación para primera prueba:

- PLA común.
- 0.2 mm layer height.
- 15-20% infill.
- Keycap lisa primero, sin relieve, para validar medidas.
- Después hacer versión con ícono o texto en relieve.
