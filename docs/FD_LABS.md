# SATURN dentro de FD Labs

**FD Labs** es el laboratorio personal de Francisco Duarte: software, electrónica, automatización y herramientas propias hechas con componentes accesibles.

## Dónde entra SATURN

SATURN es el **nodo físico** de ese ecosistema: el aparatito que tenés al lado del teclado para disparar acciones sin buscar ventanas ni atajos. La app local (Python/Flask + panel web) es el puente entre el hardware y tu flujo diario: música, volumen, apps, OBS, VS Code y comandos propios.

## Filosofía

- Hardware barato y reparable (Pro Micro + pulsadores).
- Software propio y local (sin nube, sin cuentas, sin suscripción).
- Perfiles que se adaptan a lo que estás haciendo (Media, Stream, Trabajo, FD Labs).
- Documentación honesta: qué funciona, en qué se validó y qué falta.

## Relación con ATLAS

**ATLAS** es el asistente local de FD Labs. La idea a futuro es que SATURN sea su control físico: botones para acciones frecuentes y, en v2, potenciómetros + OLED mostrando estado (perfil activo, última acción, respuesta de ATLAS).

SATURN v1 (6 botones) es la base estable. SATURN v2 (4 botones + 2 potenciómetros + OLED) será el paso hacia esa integración.
