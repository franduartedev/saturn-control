# Keycaps SATURN v1

Las keycaps le dan identidad al deck. Como los botones se reconfiguran por perfil, conviene arrancar simple e iterar.

## Opción 1: perfil Media (recomendada para mostrarlo)

```text
PLAY   PREV   NEXT
MUTE   VOL-   VOL+
```

Es la que mejor se entiende en foto y video: cualquiera adivina qué hace cada botón.

## Opción 2: neutra S1–S6 (la más flexible)

```text
S1 S2 S3
S4 S5 S6
```

No ata el hardware a un perfil. Sirve si cambiás entre Media, Stream, Trabajo y FD Labs todo el tiempo. Si las keycaps van lisas, podés sumar etiquetas o íconos intercambiables según el perfil activo.

## Recomendaciones de impresión 3D

Basado en la primera prueba del proyecto (ver [`../keycaps/README_KEYCAPS.md`](../keycaps/README_KEYCAPS.md)):

- PLA común para la primera tanda.
- 0.2 mm de altura de capa.
- 15–20 % de relleno.
- Primero una keycap **lisa**, sin relieve, para validar medidas y calce.
- Después la versión con texto o ícono en relieve.
- Si el relieve sale frágil, probá texto más grueso o íconos simples antes que letras finas.

Con 6 keycaps lisas que calcen bien ya tenés deck usable. El grabado lindo viene después.
