Guía rápida

Cómo usar SATURN

  1. Conectá el Pro Micro. En Linux debería aparecer como Arduino Leonardo HID.
  2. Probá el hardware con sudo evtest. Los botones deben mandar KEY_F13 a KEY_F18.
  3. Levantá la app con ./launch_linux.sh.
  4. Elegí un perfil, tocá una macro, cambiá etiqueta/acción/parámetros y presioná Guardar.
  5. Si multimedia no responde, instalá playerctl y verificá que tu navegador permita teclas multimedia.

Notas de FD Labs

SATURN v1.1 es la base estable para Linux. SATURN v2 puede sumar 4 botones, 2 potenciómetros, pantalla OLED y conexión con ATLAS.
