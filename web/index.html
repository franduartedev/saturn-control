Guía rápida

Cómo usar SATURN

  1. Conectá el Pro Micro (Windows: HID directo · Linux: Arduino Leonardo HID).
  2. Probá el hardware: en Linux sudo evtest debe mostrar KEY_F13 a KEY_F18; en Windows usá la vista Diagnóstico (última tecla).
  3. Levantá la app: Windows con launch_desktop.bat o el .exe · Linux con ./launch_linux.sh.
  4. Elegí un perfil, tocá una macro, cambiá etiqueta/acción/parámetros. Se autoguardia solo.
  5. Si multimedia no responde, instalá playerctl y verificá que tu navegador permita teclas multimedia.

Notas de FD Labs
