# Autoría

## SATURN Control

**Autor:** Francisco Duarte  
**Marca personal:** Fran Duarte / FD Labs  
**Inicio del proyecto:** Junio 2026  
**Versión estable inicial:** 1.0.0  

SATURN Control es un sistema de software y firmware para controlar un macro
deck físico casero basado en Arduino Pro Micro.

## Componentes

- Aplicación de escritorio para Windows.
- Panel local con UI web integrada.
- Firmware HID para Arduino Pro Micro.
- Instalador Windows.
- Scripts de soporte para Linux.

## Objetivo

El proyecto nace como parte del laboratorio personal FD Labs para construir
herramientas propias de productividad, streaming, electrónica y sistemas
embebidos.
