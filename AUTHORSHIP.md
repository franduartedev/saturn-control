# Autoría y proceso de desarrollo

## SATURN Control

**Autor y responsable del proyecto:** Francisco Duarte  
**Marca personal:** Fran Duarte / FD Labs  
**Inicio del proyecto:** Junio de 2026  
**Versión estable inicial:** 1.0.0

SATURN Control es un sistema de software, firmware y hardware para controlar un stream deck casero construido con un Arduino Pro Micro y botones físicos.

## Contribución del autor

Francisco Duarte fue responsable de:

- definir la idea y el objetivo del producto;
- diseñar y construir el dispositivo físico;
- seleccionar y conectar los componentes;
- establecer el comportamiento esperado de los botones y perfiles;
- probar la integración entre Arduino, firmware y aplicación;
- detectar errores y validar correcciones;
- definir mejoras de interfaz y experiencia de uso;
- documentar la evolución del proyecto;
- decidir el alcance y la dirección de SATURN Control dentro de FD Labs.

## Asistencia de inteligencia artificial

El desarrollo del software y parte de la documentación contó con asistencia de herramientas de inteligencia artificial.

La IA fue utilizada como apoyo para generar, revisar y ajustar código, proponer estructuras y acelerar iteraciones. El resultado fue evaluado mediante pruebas reales sobre el hardware construido por el autor.

La inclusión de asistencia de IA se documenta para presentar el proceso de forma clara y honesta. SATURN Control no se presenta como un proyecto cuyo código haya sido escrito íntegramente a mano por el autor, sino como un producto personal dirigido, construido, probado e iterado por él con apoyo de herramientas actuales.

## Componentes del proyecto

- Stream deck físico basado en Arduino Pro Micro.
- Firmware HID para interpretar botones como teclas.
- Aplicación de escritorio para Windows y Linux.
- Interfaz local para configurar macros y perfiles.
- Instalador para Windows.
- Documentación técnica y de distribución.

## Objetivo

El proyecto forma parte de FD Labs y busca explorar la integración entre programación, electrónica, automatización, streaming y herramientas de productividad accesibles.
