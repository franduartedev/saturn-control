# Roadmap

## v1.0.0

- Macro deck funcional con Pro Micro.
- UI de configuración.
- Diagnóstico de teclas.
- Perfiles.
- Firmware estable.
- Build e instalador Windows.

## Próximas mejoras

- Exportar e importar configuraciones.
- Pantalla de calibración guiada.
- Mejoras visuales en iconos y estados de macros.
- Editor más simple para acciones OBS.
- Autoactualizador básico.
- Firma digital del instalador.
- Página oficial de descarga FD Labs.
- Soporte futuro para encoder, potenciómetro o LCD.
- Builds Linux empaquetados como binario/AppImage.

## Ideas futuras

- Integración con Atlas / asistente local.
- App móvil o panel remoto.
- Marketplace simple de perfiles.
- Modo avanzado para streamers.
- Versión hardware con carcasa impresa 3D.
